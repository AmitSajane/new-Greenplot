How it works

  • ONE SCREEN Replaces Login / OTP / password. Farmer fills name, role, phone, WhatsApp, location → taps Continue.
  • ROLE ROUTING Farmer → Farmer Dashboard · Land Owner → Owner Dashboard (the toggle decides which app they see).
  • LOCATION One-tap GPS auto-detect (village, district, state via reverse-geocode) with a manual fallback.
  • WHATSAPP Just one phone field + a checkbox "This number is also on WhatsApp" (on by default) — no second field.
  • SAVED Profile stored locally (and to Supabase when backend is on) → next launch skips onboarding and goes straight to the right dashboard.
  • NEW FIELDS Adds location & hasWhatsapp (boolean) to the user profile (name, role, phone already exist).
